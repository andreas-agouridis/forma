How to generate an AI image in Forma

Forma is a free-to-use browser interface for text-to-image generation through Pollinations. It does not host its own image model. Your provider account supplies generation access, credits and model permissions.

  1. Open the image studio and choose Connect AI. Request a connection code, open Pollinations, approve the matching code and return to Forma.
  2. Write a description of the image. Include a subject, environment and lighting, then select a visual style and image model.
  3. Choose an aspect ratio and press Generate image. You can also use Ctrl+Enter on Windows or Command+Enter on macOS.
  4. Download the completed image at the dimensions returned by the provider. Use Use settings to start another image from the same creative direction.

The connection token stays in page memory. Refreshing the page requires reconnecting. Drafts and recent images are stored separately in your browser when storage is available.

What makes a good AI image prompt?

A useful image prompt describes what should be visible and how it should look. Start with the main subject, then add the setting, composition, materials, lighting and mood. A clear description usually gives the model more direction than a long list of generic quality words.

Subject + setting + composition + materials + lighting + mood

Instead of “a nice futuristic building,” try “a low, circular research station on a rocky coast, weathered white concrete and curved glass, eye-level wide shot, overcast morning light, quiet and remote.”

Keep the instructions compatible

A close-up and an expansive aerial view ask for different compositions. Give one main direction. If you want exact words inside the image, put them in quotation marks and keep the text short. Image models can still make spelling, counting and anatomy errors.

Use the prompt assistant deliberately

Refine with AI makes a separate text-model request through Pollinations. It asks the assistant to preserve your subjects, quantities, language and quoted text while clarifying visual detail. Review the result before generating. Undo refinement restores the previous prompt.

The advanced composition and detail guidance checkbox is different: it appends a short instruction locally and does not make an additional AI request.

Three image prompts to make your own

Editorial product photography

A small ceramic espresso cup on a warm limestone counter, pale sage glaze with a handmade texture, three-quarter close-up, soft light from a window on the left, gentle shadows, a calm editorial photograph.

Playful 3D illustration

A tiny greenhouse balanced on a floating island, translucent glass panels and oversized ferns, rounded clay-like rocks, isometric composition, peach clouds, soft studio lighting, a playful miniature world.

Cinematic landscape

A lonely observatory above a sea of clouds, dark volcanic rock in the foreground, a narrow path leading toward the building, blue-hour sky and warm windows, wide cinematic framing, a sense of discovery.

Change a single feature—material, weather, time of day or camera position—to explore variations. The studio’s inspiration cards provide more ready-to-edit prompts.

Which image model should I choose?

Use Z-Image Turbo as a quick starting point. Try other models when you need different detail, typography or composition. These are practical starting points rather than promises about every result. Aspect ratio, seeds and art direction

Aspect ratio controls the requested shape: square 1:1, landscape 16:9, portrait 9:16, or classic 4:3. Forma requests 1024×1024, 1280×720, 720×1280, or 1152×864 pixels respectively. Models may return different dimensions; the canvas shows the actual result.

Seeds guide randomness on supported models. A matching prompt, model, settings and seed can produce similar results, but provider changes and model behavior mean exact reproduction is not guaranteed. Retry uses the same request and seed, including on models that ignore seeds.

Art direction adds lighting and composition instructions to the prompt. “As described” leaves those choices to your text. “Exclude from scene” also adds an ordinary prompt instruction; it is not a dedicated negative-prompt API parameter.

Render quality is enabled only for GPT Image 1 Mini. High quality can consume more provider credits. Other listed models manage their own quality.

Why did image generation fail?

Connection problems, unavailable models and provider budgets require different fixes. Forma keeps your prompt and shows a specific message where the provider supplies enough information.

Connection expired or invalid — HTTP 401

Choose Connection settings and reconnect. Approve a fresh code on Pollinations, return to the studio, then retry. Tokens are intentionally not kept after a page refresh.

No available credits — HTTP 402

Check your Pollinations dashboard ↗ for an exhausted account balance or per-key budget. Free credits, if offered, are controlled by Pollinations. Retrying immediately will not add credits.

Model or permission restriction — HTTP 403 or 404

Check whether your authorized connection permits the model. Some models require paid balance. Refresh the model catalog and select an available model. A 403 can also reflect a provider restriction on the request.

Rate limit or temporary outage — HTTP 429 or 5xx

Forma retries eligible temporary errors up to two times, with backoff and the provider’s Retry-After delay. It waits automatically for delays up to one minute within a bounded request window. Longer delays show a wait message instead. Retries keep the same request so the provider can reuse an in-progress or cached generation.

Offline, blocked request or timeout

Check your connection and browser content blockers. A request can time out even when the provider is still processing it. Retry same request preserves the previous model, settings and seed. Cancelling stops waiting in your browser; it does not guarantee that provider work or billing stops.

Image history did not survive a reload

Private browsing, blocked storage, storage limits and clearing site data can remove local history. Forma reports when it can keep images only for the page session. Download important images as separate files.
