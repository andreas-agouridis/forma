Here’s what the Forma application stores, where requests go, and how to stay in control of your creations.

Application data practices · Updated September 20, 2026

What Forma does

Forma is a static HTML, CSS and JavaScript image studio. It connects your browser directly to Pollinations for AI generation and prompt refinement. The application includes no analytics scripts, advertising trackers or Forma-operated account database.

Your hosting provider may maintain ordinary access logs. The practices of a website operator or hosting service are separate from the application behavior described here.

What stays in your browser

  • Your current draft and settings are saved in localStorage, when available, so you can return to them later.
  • Up to 12 recent generated images, their prompts and settings are saved in IndexedDB, when available. Image files are stored as local browser blobs, not published into a shared Forma gallery.
  • Your provider access token is kept in page memory only. It is not stored in localStorage, IndexedDB, a URL or application logs. Refreshing the page requires reconnecting.

If browser storage is blocked or full, the studio continues with session-only data and displays a storage message. Browser storage is not a backup: download the images you want to keep.

What is sent to Pollinations

When you connect, the browser requests a device code and checks whether you have approved it. Pollinations controls sign-in, authorization, model permissions, budgets and revocation. Forma does not receive your provider password.

When you generate, your browser sends the assembled image prompt, model, dimensions, seed and any supported quality settings to Pollinations. When you select Refine with AI, it sends your description and aesthetic to a text model through Pollinations. Access tokens are supplied in authorization headers on authenticated API calls.

The public model catalog is also requested to show availability, health and price information. Pollinations and its upstream providers process generation requests under their own data practices. This application does not promise that provider requests are anonymous or that providers retain no data. Visit Pollinations ↗ for its current policies.

Fonts and reference photography

The pages request fonts from Google Fonts. Inspiration cards load reference photographs from Unsplash. Those services receive the normal network information associated with loading a resource, such as your IP address. Image prompts and connection tokens are not sent to either service by the application.

System font fallbacks and local CSS artwork keep the interface usable if external assets do not load.

How to remove your data

  • Choose Clear local history in the studio to remove saved image records. The currently displayed canvas remains available until replaced or the page is closed.
  • Clear this site’s storage in your browser settings to remove both draft and image history.
  • Choose Disconnect this session in Connection settings, or reload the page, to discard the in-memory token.
  • To revoke the authorization itself, use your Pollinations dashboard ↗. Disconnecting locally does not revoke the provider-side grant.

Files you download are saved outside the application’s browser storage. Delete those files separately if needed.

About sharing and downloads

Copy prompt copies only the assembled generation prompt. Downloads contain the image returned by the provider, at its actual dimensions. Forma does not publish your result to a social network or upload it to an additional service.

Ownership, licensing, public-media behavior and permitted uses of provider-generated content depend on the applicable provider and model terms.
